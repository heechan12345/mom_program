가족 입출금 내역 정리 프로그램 - 사용법
=========================================

이 프로그램은 농협 / 우리은행 / 하나은행에서 온 입출금 문자 스크린샷을
읽어서, 은행별로 엑셀에 자동 정리해줍니다.


1. 문자 스크린샷 준비하기
--------------------------
휴대폰에서 은행 문자(또는 문자를 모아둔 카카오톡 대화방)를 캡처(스크린샷)
합니다. 여러 개를 한 화면에 캡처해도 되고, 문자 한 건씩 따로 캡처해도
됩니다.

캡처한 사진을 컴퓨터로 옮깁니다. 예:
  - 카카오톡 "나에게 보내기"로 사진을 보낸 뒤, 컴퓨터 카카오톡에서 저장
  - 휴대폰을 USB로 연결해서 사진 폴더 복사
  - 이메일에 사진 첨부해서 보낸 뒤 컴퓨터에서 다운로드


2. 프로그램 실행하기
--------------------------
"입출금정리.exe" 파일을 더블클릭해서 실행합니다.

프로그램을 처음 열면 한국어 OCR(문자 인식) 기능이 있는지 자동으로
확인합니다. 만약 아래와 같은 오류가 뜨면:

  "한국어 OCR 언어팩이 없습니다"

Windows 설정에서 언어팩을 추가해주세요:
  설정 > 시간 및 언어 > 언어 및 지역 > "한국어" 클릭 > 옵션
  > "기능 추가"에서 "광학 문자 인식"을 추가

추가한 뒤 프로그램을 다시 실행하면 됩니다.


3. 문자 저장하기
--------------------------
1) "이미지 선택" 버튼을 눌러 1번에서 옮겨둔 스크린샷 사진들을 선택합니다
   (여러 장을 한꺼번에 선택할 수 있습니다).
2) "문자 저장하기" 버튼을 누르면 자동으로 읽어서 엑셀에 저장합니다.
3) 처리가 끝나면 몇 건이 새로 저장됐는지 알려줍니다.
4) "엑셀 열기" 버튼을 누르면 정리된 엑셀 파일이 바로 열립니다.

엑셀 파일은 항상 아래 위치에 저장됩니다 (파일을 지우지 않는 한 계속
누적됩니다):
  내 문서\가족_입출금정리\거래내역.xlsx

같은 문자를 다시 저장해도 중복으로 쌓이지 않습니다.


4. 엑셀 파일 구성
--------------------------
  - 전체내역   : 모든 거래를 날짜순으로 모아둔 표
  - 농협 / 우리은행 / 하나은행 : 은행별로 따로 정리한 표
  - 일별합계   : 날짜별, 은행별 입금/출금 합계
  - 적요별합계 : "무엇으로" 입출금이 됐는지(거래처/이름)별 합계
  - 미인식     : 글자 인식이 잘 안 돼서 자동으로 정리하지 못한 문자
                (원본 사진 이름과 함께 남아있으니 필요하면 직접 확인)


5. "확인필요" 표시가 뜨는 경우
--------------------------
사진 속 숫자를 잘못 읽는 경우가 드물게 있을 수 있습니다. 프로그램이
"이전 잔액 + 입출금액 = 다음 잔액"이 맞는지 자동으로 검사해서, 계산이
맞지 않으면 "전체내역" 시트의 "확인필요" 칸에 "예"라고 표시합니다.
이런 줄은 원본 사진과 대조해서 숫자가 맞는지 확인해주세요.


문의: 프로그램에 문제가 있으면 만든 사람에게 알려주세요.
