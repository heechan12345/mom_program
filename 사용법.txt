가족 입출금 내역 정리 프로그램 - 사용법
=========================================

이 프로그램은 농협 / 우리은행 / 하나은행에서 온 입출금 문자를, 문자 백업
XML 파일(예: 'SMS Backup & Restore' 앱으로 내보낸 파일)에서 읽어 은행별로
엑셀에 자동 정리해줍니다. 스크린샷/OCR 없이 문자 원문을 그대로 읽기 때문에
정확도가 매우 높습니다.


1. 문자 백업 XML 파일 준비하기
--------------------------
휴대폰에서 문자 백업 앱(예: 'SMS Backup & Restore')으로 전체 문자를 XML
파일로 내보냅니다. 파일 이름은 보통 "sms-날짜시간.xml" 형태입니다.

내보낸 파일을 컴퓨터로 옮깁니다. 예:
  - 카카오톡 "나에게 보내기"로 파일 전송 후 컴퓨터에서 저장
  - 휴대폰을 USB로 연결해서 파일 복사
  - 이메일 첨부 등


2. 프로그램 실행하기
--------------------------
"입출금정리.exe" 파일을 더블클릭해서 실행합니다. (Python 설치 불필요, 인터넷
연결도 필요 없습니다.)


3. 문자 저장하기
--------------------------
1) 화면 상단의 "연도"와 "월"을 원하는 기간으로 입력합니다 (기본값은 오늘
   날짜 기준 이번 달).
2) "XML 파일 선택" 버튼을 눌러 1번에서 옮겨둔 XML 파일을 선택합니다.
3) "문자 저장하기" 버튼을 누르면 지정한 연/월의 거래만 골라 자동으로
   엑셀에 저장합니다.
4) 처리가 끝나면 몇 건이 새로 저장됐는지 알려줍니다.
5) "엑셀 열기" 버튼을 누르면 정리된 엑셀 파일이 바로 열립니다.

엑셀 파일은 항상 아래 위치에 저장됩니다 (파일을 지우지 않는 한 계속
누적됩니다). 다음 달 것을 정리하고 싶으면 연/월만 바꿔서 같은 XML 파일(또는
새로 내보낸 파일)로 다시 처리하면 됩니다:
  내 문서\가족_입출금정리\거래내역.xlsx

같은 문자를 다시 저장해도 중복으로 쌓이지 않습니다.


4. 엑셀 파일 구성
--------------------------
  - 전체내역   : 모든 거래를 날짜순으로 모아둔 표
  - 농협 / 우리은행 / 하나은행 : 은행별로 따로 정리한 표
  - 일별합계   : 날짜별, 은행별 입금/출금 합계
  - 적요별합계 : "무엇으로" 입출금이 됐는지(거래처/이름)별 합계
  - 미인식     : 처리하지 못한 문자 (원본과 함께 남아있으니 필요하면 직접 확인)


5. "확인필요" 표시가 뜨는 경우
--------------------------
프로그램은 "이전 잔액 + 입출금액 = 다음 잔액"이 맞는지 자동으로 검사해서,
계산이 맞지 않으면 "전체내역" 시트의 "확인필요" 칸에 "예"라고 표시합니다.
문자 원문을 그대로 읽기 때문에 이 표시가 뜨는 경우는 드물지만, 뜬다면
중간에 빠진 문자(백업되지 않은 문자 등)가 있을 가능성이 있으니 해당 구간을
확인해주세요.


문의: 프로그램에 문제가 있으면 만든 사람에게 알려주세요.
